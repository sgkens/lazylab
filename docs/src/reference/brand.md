## The mark

<p class="brand-row"><img src="/assets/brand/lazylab-mark.svg" alt="The lazylab mark: a flask with a rising zz on an orange tile" width="96" height="96"></p>

A flask with a rising "zz" on an ember tile. The flask is the *lab*: GitLab, and a workbench on your own machine. The zz is the *lazy*: lazylab watches pipelines, tokens and merge requests so you do not have to.

Write the name in lowercase, `lazylab`. The command-line client is `lazy`.

## Files

The kit lives in [`brandkit/`](https://gitlab.com/sgkens/lazylab/-/tree/main/brandkit) in the repository. Open its `index.html` for the full guide with downloads.

| Need | File |
|---|---|
| Icon, avatar, favicon | `svg/lazylab-mark.svg`, `svg/favicon.svg`, `png/lazylab-mark-512.png` |
| Logo with the name | `svg/lazylab-logo-light.svg` (light backgrounds), `svg/lazylab-logo-dark.svg` (dark backgrounds) |
| One colour | `svg/lazylab-mark-ink.svg`, `svg/lazylab-mark-white.svg` |
| Link preview, 1280 × 640 | `png/lazylab-social.png`, `webp/lazylab-social.webp` |
| Colour tokens | `tokens.css` |

## Colour and type

| Token | Hex | Use |
|---|---|---|
| Ember 400 / 600 | `#fb923c` / `#ea580c` | The mark's gradient; accent on dark |
| Ember 700 | `#c2410c` | Accent and links on light |
| Ink 950 / 900 / 800 | `#09090b` / `#18181b` / `#27272a` | Backgrounds, surfaces, borders |
| Paper | `#fafafa` | Light background, wordmark on dark |
| Pass / Fail / Wait | `#34d399` / `#fb7185` / `#fbbf24` | Status only |

Plus Jakarta Sans for the interface and the wordmark; JetBrains Mono for code and the CLI.

## Rebuild

Edit `brandkit/build.mjs`, never the generated files, then rebuild. The build refreshes the copies used by the app (`src/assets/brand/`) and this site (`docs/src/assets/brand/`).

```bash
# Shell: bash, brandkit/
bun install && bun run setup    # once: fonts, opentype.js and Playwright's Chromium
bun run build
```
